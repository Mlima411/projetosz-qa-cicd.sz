# 🧪 Projeto QA Automation - Cypress & CI/CD

Este repositório contém a automação de testes de ponta a ponta (E2E) utilizando **Cypress**, integrado a uma pipeline de **CI/CD** via **GitHub Actions** para execução e geração automática de relatórios e vídeos das suítes de testes.

## 🚀 Tecnologias Utilizadas

* [Cypress](https://www.cypress.io/) - Framework de testes automatizados E2E
* [Node.js](https://nodejs.org/) - Ambiente de execução
* [GitHub Actions](https://github.com/features/actions) - Automação da pipeline de CI/CD

## ⚙️ Funcionalidades da Pipeline de CI/CD

* Execução automática dos testes E2E a cada `push` ou `pull request` na branch principal (`main`).
* Gravação e geração de vídeos das execuções de testes.
* Upload de artefatos de teste para consulta direta no GitHub Actions.
